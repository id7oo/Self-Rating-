# PEC Self-Rating

An interactive version of the **Standard PEC Self-Rating Questionnaire** (Personal Entrepreneurial Competencies).

- 55 statements, one at a time, rated 1 (Never) to 5 (Always)
- Scored exactly as the paper scoring sheet, including the correction factor (items 11, 22, 33, 44, 55)
- Results: entrepreneur type, PEC profile chart (0–25), strengths, growth tips, full score sheet
- No sign-in. Answers stay in the browser and clear on refresh.

**Live site:** https://id7oo.github.io/Self-Rating-/
